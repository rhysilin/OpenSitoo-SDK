# 身份、组织与命名空间

开发者中心0.6.0提供独立身份与环境配置：你可以管理组织成员、命名空间和开发/测试访问凭据。它使用平台统一身份服务，但不使用模型API密钥作为登录凭据。默认提供本地开发/测试；生产命名空间凭据只读；项目发布/目录可由运维显式独立配置，详见[生产发布指南](/center/production-publishing)。生产账号自助注册尚未开放。

## 开始前

由平台操作者提供可访问的开发者中心地址、统一身份账号及邀请资格。默认本机地址为http://127.0.0.1:18683；127.0.0.1只能在运行该服务的机器访问，不是对外服务器地址。受邀名单按同一OIDC身份服务的稳定标识登记，账号密码只在身份服务页面输入。没有环境或邀请时，联系操作者取得，不能换成New API模型令牌。

## 登录与选择范围

点击“统一身份登录”，在身份服务完成登录，返回后检查姓名、身份标识和工作范围。个人范围允许申请个人命名空间；组织范围由成员关系决定，选择器只显示你有权访问的组织。切换后旧会话失效，其他标签页需要刷新或重新登录；不要保存旧CSRF继续操作。

创建组织：填写组织名称，点击“创建组织”。成功后工作范围切换到新组织，你成为所有者。组织名称不等于命名空间；后者是全局唯一的发布归属标识。组织身份也不自动取得平台审核或发布职责。

## 邀请成员与角色

在组织成员区填入目标用户当前身份页显示的稳定标识，选择角色后发送。邀请默认24小时有效，不发送邮件；目标登录后在待接受邀请区看到组织名称和角色，点击“接受邀请”，再切换到该组织。组织管理者点击“刷新范围数据”查看最新成员列表。

| 角色 | 可以做什么 |
| --- | --- |
| 所有者 | 管理成员和角色、申请命名空间、管理组织凭据、查看审计；不能移除或降级最后所有者 |
| 管理者 | 管理开发者/只读成员、申请命名空间、管理组织凭据、查看审计；不能操作所有者/管理者角色 |
| 开发者 | 读取组织成员和命名空间、创建凭据、撤销自己创建的凭据；不能管理成员或申请组织命名空间 |
| 只读成员 | 读取当前组织成员和命名空间；不能管理凭据或改变组织状态 |

邀请仅目标身份可接受，重复或过期请求拒绝；邀请者撤权后未接受邀请失效。更改成员角色或移除时，其旧会话和组织工具凭据立即撤销，重新登录才能使用新权限。成员所属其他组织不会因本组织凭据自动获得访问权。

## 申请命名空间

个人范围，或组织所有者/管理者，在命名空间区填写名称并申请。名称3–40字符，以ASCII字母开头，允许字母/数字/连字符，存储为小写；平台名称保留。成功后列表显示规范化名称。`Team-Tools`与`team-tools`同名；已占用返回冲突，不覆盖他人归属。

## 创建与撤销工具凭据

切换组织后填写凭据名称，选择“开发”或“测试”，点击“创建凭据”。当前权限仅`namespace:read`，30天有效，不能用于成员管理、签名或跨环境访问。生产配置只允许选择“生产”，权限仍仅namespace:read，不能用于生产项目发布。原文仅显示一次，保存到安全凭据配置；不要写入项目包、Git、截图或日志。点击“隐藏凭据”清除页面展示；原文丢失时撤销旧凭据再创建，不向平台索取历史原文。

```powershell
# 原文来自开发者中心刚创建的test凭据；占位符须替换，禁止提交到Git。
$env:SITOO_TEST_TOKEN = '<刚创建的test凭据>'
Invoke-RestMethod 'http://127.0.0.1:18683/v1/environments/test/namespaces' -Headers @{Authorization="Bearer $env:SITOO_TEST_TOKEN"}
Remove-Item Env:SITOO_TEST_TOKEN
```

成功返回当前组织的`namespaces`列表，可以为空。development凭据访问test返回403；撤销后返回401。退出浏览器只撤销当前会话，不能替代工具凭据撤销。

## 遇到错误

未受邀：核对实际身份服务和稳定标识，请操作者登记邀请。命名空间冲突：选择新名称，不反复覆盖。邀请不可用：请管理者重新发送，核对身份/过期/撤权。会话或CSRF失效：刷新/重新登录并确认工作范围。缺权限：按上表联系组织所有者，不手工伪造组织ID或身份字段。

准确请求和错误结构见[开发者中心HTTP](/reference/developer-center)。服务支持范围见[版本](/support/versions)；应用执行权限仍按[权限与确认](/guides/permissions)独立处理。

## 核对环境与会话

登录前先核对地址和页面“当前环境”。开发/测试与生产配置使用独立数据库、OIDC客户端及Cookie；同名命名空间可在不同部署中独立存在，不能携带一个环境的凭据访问另一个环境。生产配置要求HTTPS和可信身份服务，客户端秘密保存在服务端，浏览器不读取。HTTPS本机夹具只能检查协议，不代表真实生产账号已经开通；以操作者提供的正式入口和身份为准。

生产会话八小时绝对到期、闲置30分钟到期，单账号最多5个并行会话；超过时最早签发的会话失效。重新登录当前浏览器会撤销该浏览器旧会话。若后台任务页面返回401，先重新登录再查询原记录，不能把失败当作许可重发。

生产配置使用Secure/HttpOnly/SameSite=Lax的独立Host Cookie；不要复制Cookie或通过修改参数改变环境。原开发/test凭据不会获得production权限。操作者从受邀名单移除身份并重启后，旧会话及工具凭据被撤销；重新邀请也不能复活旧秘密。服务尚未接入身份服务禁用事件的即时同步，撤权需联系操作者执行；组织成员撤权按本页既有规则立即生效。

当前本地测试入口与旧版本可以由操作者分别保留；通过[中心HTTP参考](/reference/developer-center)的health核对实际版本与deploymentEnvironment，不能按网页端口或模型账户数字ID推断身份归属。

若同时访问多个开发中心，请操作者启用isolatedSessionCookies。Cookie不按端口隔离，只有不同Cookie名才能避免同一浏览器中的登录覆盖；默认旧开发配置仍兼容原名字。0.5.0配置能力需核对实际服务版本，较旧入口不具备本页新增配置。
